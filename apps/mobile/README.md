# apps/mobile

App mobile **para salões/profissionais** (fase 1 — sem gateway de pagamento).

- **Stack alvo:** React Native (Expo) + TypeScript + Firebase (Auth + FCM).
- **Foco fase 1:** notificações **push**
  - resumo diário do modo assistido (08:00);
  - lembretes operacionais de atendimentos;
  - avisos de assinatura em atraso/pendente.
- **Não** é baixado pelo cliente final nesta fase (só quando existir gateway de pagamento — fase 2).

> Scaffolding Expo será criado na fase "Mobile". Reaproveita `@socio247/domain`.
